Essa versão do jogo da cobrinha adiciona diversas ferramentas diferentes a proposta original do snake, não é apenas uma cópia do original, mas uma releitura. O jogador usa WASD ou as setas para se movimentar com a cobra, o objetivo é fazer o máximo de pontos possíveis comendo as frutas brilhantes que aparecem no caminho. As frutas douradas dão mais pontos, porém aparecem aleatoriamente e duram poucos segundos. Caso a cobra bata a cabeça nas paredes ou nos obstáculos, é fim de jogo. Quando o jogador morre, aparece uma tela que mostra os recordes e permite que o jogador adicione 3 letras para deixar sua melhor pontuação registrada.
